# Archive Extractor

**A simple, user-friendly archive extraction tool for Linux Mint Cinnamon.**

Developed by **Favor Samuel Nambafu**

## About the Project

Archive Extractor is a desktop application designed to make extracting archives and accessing extracted applications easier for Linux users, particularly beginners who may not be comfortable using the terminal.

Linux offers powerful command-line tools for handling archives, but not every user knows which commands to use or how to run an application after extracting it. Archive Extractor aims to make these tasks more accessible through a graphical interface.

## The Problem It Solves

New Linux users can struggle with tasks such as:

- Extracting ZIP and TAR archives without using terminal commands.
- Understanding where extracted files are saved.
- Finding and launching applications after extracting downloaded packages.
- Creating desktop or application-menu shortcuts.
- Monitoring extraction progress and handling existing files safely.

Archive Extractor brings these tasks together in one desktop application, helping users work with archives more confidently.

## Features

- Extract ZIP and TAR archives, including common compressed TAR formats.
- Drag and drop archives into the application.
- Display extraction progress.
- Cancel extraction when needed.
- Protect against unsafe archive paths.
- Skip existing files instead of silently overwriting them.
- Detect extracted applications and help launch supported files.
- Create desktop launchers and application-menu shortcuts.
- Open extracted folders directly.

## Who Is It For?

Archive Extractor is intended especially for:

- New Linux users.
- Linux Mint Cinnamon users.
- Users who prefer graphical applications over terminal commands.
- Anyone who wants a simpler way to extract archives and access extracted applications.
